# 业务模型与边界

到期对象、法律保全令、派生依赖和销毁目标共同决定可销毁性；保全中的子对象会冻结其源对象。

## 实体关系

Batch 关联多个 Subject 与 SourceFile；SourceFile 的原始字节和 SHA-256 不覆盖，RawEvent 引用来源行；RuleVersion 被 Evidence 引用；一次 Run 关联多个 Decision、Evidence、Issue。非法输入留下 Issue，不写出无依据的成功结论。

## 状态和失败

导入与身份校验结束后 Run 进入已校验；有无法判定主体时进入待核，否则已判定。规则版本变化产生新 Run，旧 Decision 保留。源哈希冲突、身份冲突、依赖环、证据缺口和执行失败各有独立错误或问题码。写操作只允许显式沙箱，原始来源保持只读。

## 首版以外的自然扩展

多法域规则冲突、动态视图依赖、软删观察期、介质级擦除证明、外部签名校验、共享对象分摊、撤销请求、证明链复签。以上均未实现。

## 访问扫描与会话评估

UsageLog 以原始字节和 SHA-256 冻结 JSONL 扫描日志，UsageScan 保存逐行进/出记录；会话推断不写回扫描表，也不被裁决、删除请求、交接或回收读取。UsageAssessment 以独立 assessment_id 冻结一次评估，绑定 log_id、源哈希、gap、clock_contract、cutoff、session_limit、参数摘要与算法版本；同参幂等、异参冲突，日志新版本另建记录。

配对阶段按 subject+actor+device 校验 enter/exit 次序、重复或缺失出口，并区分截止边界导致的未闭合区间（待核）与结构错误。reported 口径在原始报告时间线上合并区间；guaranteed 口径把每台设备建模为一个共享的整数秒偏移变量，域为该设备全部扫描 ±error_seconds 的交集，设备间独立。会话数只在跨设备端点（含 gap 平移端点）相交的整数超平面上变化，因此枚举每变量的域界与超平面边界整数及其两侧邻点构成的笛卡尔积即可覆盖全部常值单元，给出精确最小/最大会话数与可重放偏移见证；运行成本取决于区间数，与误差窗口宽度无关。usage-verify 从冻结字节重建扫描、重算结论并独立重放见证，篡改扫描、阈值或见证均产生问题码。
