# 业务模型与边界

到期对象、法律保全令、派生依赖和销毁目标共同决定可销毁性；保全中的子对象会冻结其源对象。

## 实体关系

Batch 关联多个 Subject 与 SourceFile；SourceFile 的原始字节和 SHA-256 不覆盖，RawEvent 引用来源行；RuleVersion 被 Evidence 引用；一次 Run 关联多个 Decision、Evidence、Issue。非法输入留下 Issue，不写出无依据的成功结论。

## 状态和失败

导入与身份校验结束后 Run 进入已校验；有无法判定主体时进入待核，否则已判定。规则版本变化产生新 Run，旧 Decision 保留。源哈希冲突、身份冲突、依赖环、证据缺口和执行失败各有独立错误或问题码。写操作只允许显式沙箱，原始来源保持只读。

## 首版以外的自然扩展

多法域规则冲突、动态视图依赖、软删观察期、介质级擦除证明、外部签名校验、共享对象分摊、撤销请求、证明链复签。以上均未实现。

## 跨法域归属与保留规则版本

`jurisdiction_origin` 与 `jurisdiction_transfer` 两类原始事件在 `as_of` 之前按 `(at, event_key)` 回放为半开区间。对象在某时点的持有地集合只由这些事件及对象标签推导，不看导入行顺序；未知持有地、同期重叠、从无归属地转出、关闭后再次产生、标签事件落在持有区间外均为待核。

政策按法域声明（`jurisdictions` 的内联版本或 `policy_versions` 列表），每个版本带 `effective_from`/`effective_until`，区间半开。若 `as_of` 没有唯一有效版本，结论为待核，不沿用上一版本。期限起点分 `created`（该法域自身的产生事件）、`terminated`、`last_use`；起点证据缺失时只能报该法域缺口，不能用另一法域的 created 或其他事件代填。

法律保全令独立回放，不因转移解除；依赖闭包仍然把被保留子对象的资产冻结，并把子对象来源证据上溯。

责任合同在运行时冻结（`run_jurisdiction`，含授权依据与快照摘要）：

- `concurrent`：所有仍有效的来源地与持有地政策期限都须届满；
- `single_successor`：仅当冻结的转移事件带有可核验的 `succession` 记录（含依据，且其证据事件键存在于来源中）时，才把原持有地排除；否则仍并存。没有 `succession` 字段的转移、或证据键缺失，都不算承接。

报告逐法域给出政策版本、生效区间、所用起点事件、届满日与承接/排除依据。旧 run 的证据行按 run 固定，迟到事件只影响新 run。
